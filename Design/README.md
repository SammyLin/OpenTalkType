# OpenTalkType Icon

OpenTalkType uses a quiet waveform settling onto a text baseline beside an insertion caret, capturing speech becoming clean, editable text without relying on microphone imagery; regenerate the complete macOS asset catalog — `../OpenTalkType/Assets.xcassets/AppIcon.appiconset`, written in place — by running `./make-icons.sh` from this directory (install librsvg with `brew install librsvg` only if Quick Look cannot render the SVG).
